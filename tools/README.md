# tools — 최종 모델 코드

웹사이트와 같은 모델을 실행하는 최종 코드입니다.
실측 앵커 데이터가 코드 안에 포함되어 있어, 별도 데이터 파일 없이도 동작합니다.

| 파일 | 역할 |
|---|---|
| `멘사_IQ_오답예측기.bat` | 나이·IQ를 입력하면 오답 개수를 계산하는 콘솔 프로그램 |
| `웹사이트_생성.py` | `.bat`의 모델 데이터를 `index.html`에 주입 |

## 실행

Windows에 Python 3가 설치되어 있어야 합니다.

### 예측기

```bat
tools\멘사_IQ_오답예측기.bat
```

실행하면 기준표·보정표·추가검증 자체 검증 결과가 먼저 출력됩니다.

### 웹사이트 데이터 갱신

저장소 루트에서:

```bat
python tools\웹사이트_생성.py
```

`index.html` 안의 `/*__MODEL_DATA_START__*/ ... /*__MODEL_DATA_END__*/` 블록이 새 데이터로 교체됩니다.

## 구조

- 모델의 원본은 `멘사_IQ_오답예측기.bat` 하나입니다.
- `웹사이트_생성.py`는 그 파일을 실행해 모델 값을 읽고, `index.html`에 넣습니다.
- 따라서 모델을 고칠 때는 `.bat`만 수정하고 생성기를 다시 실행하면 됩니다.

## 참고

- 웹사이트의 계산 로직은 `index.html` 안에 있습니다.
- 결과는 실측값을 바탕으로 한 추정치입니다.
